Create a simulation that uses the inverted pendulum environment from the Gymnasium library (https://gymnasium.farama.org/environments/mujoco/inverted_pendulum/) and renders this. The simulation should have the following:
1) The simulation opens with a screen providing three choices. The choices are manual control, PID control and reinforcement learning control.
2) With manual control, the user can control the pendulum using the keyboard.
3) With PID control, a PID controller is used, and the user can tweak the P, I and D gains of the PID controller using three sliders.
4) With RL control, an RL agent is trained using stable baselines. The user can fine tune the training hyperparameters before launching the training. Once a model is trained, it is saved as a checkpoint. The next time the user runs the simulation, the user can choose to use the trained model or train a new model.

When creating the simulation, make sure each of these control algorithms are implemented in their own respective functions, in a separate file. Make a Jupyter notebook that also contains these functions, in which the functions are left blank, and the algorithms are not implemented. Create Markdown cells in this notebook that explain briefly how these algorithms work and gives instructions on how to implement them. The actual implementation is left as an exercise to the reader. Create a solution notebook with the implemented functions. Add a script to the notebook that exports the coded functions into the .py file used by the simulation. Once the reader is done coding the functions, they can run this cell to generate the .py file, then run the simulation to test how their algorithm runs in their simulation.
